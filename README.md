🎓 EBAC — Módulo 16: Catálogo de Produtos (React + Vite)

## 📖 Sobre

Catálogo de produtos renderizado por componentes React:

- `src/components/ProdutoCard.tsx` — card de produto reutilizável
- `src/pages/Home.tsx` — listagem

## 🚀 Como rodar

```bash
npm install
npm run dev
```

## 🛠️ Tecnologias

React • Vite • JavaScript/TypeScript

## 💡 O que aprendi

- Componentização de cards de produto em React
- Estrutura de projeto Vite (public/, src/, vite.config.js)
